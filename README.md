# RIX_SUPPORT_BOT 🎫

ربات پشتیبانی تیکتمحور چند-مستأجری برای تلگرام — پایتون خالص، بدون حتی یک
کتابخانه جانبی. هر کسب‌وکار یک «مستأجر» است: تیم، مشتریان، تنظیمات و گزارش
های خودش را دارد و همه روی یک نصب اجرا می‌شوند.

## امکانات

- **چند-مستأجری**: چند کسب‌وکار روی یک ربات، با مرز داده در سطح SQL
- **تیکت**: ایجاد با دکمه (بدون تایپ دستور)، اولویت، وضعیت، انتقال بین اپراتورها
- **یادداشت داخلی**: اپراتورها یادداشت می‌گذارند، مشتری نمی‌بیند
- **تخصیص خودکار**: کمترین بار کاری، با سقف ظرفیت برای هر اپراتور
- **SLA**: هشدار تأخیر پاسخ، ساعت کاری و پیام خارج از ساعت
- **نظرسنجی رضایت**: امتیاز ۱ تا ۵ بعد از بستن تیکت
- **CRM**: پروفیل مشتری، تگ، جستجوی سریع با نام/آیدی/تگ
- **وریفای مشتری**: ادمین آیدی عددی می‌دهد → ربات کد ۶ رقمی می‌فرستد
  (با دکمه کپی) → مشتری کد را می‌فرستد → پنلش باز می‌شود
- **پنل داخل تلگرام**: منوی دکمه‌ای برای مالک/ادمین/اپراتور — بدون وب‌اپ
- **دکمه‌های رنگی**: `style=primary/success/danger` (Bot API 8.3+)
- **گزارش**: میانگین اولین پاسخ، تعداد تیکت، امتیاز رضایت، بار کاری تیم
- **لاگ اقدامات**: هر تغییر مهم در جدول audit ثبت می‌شود
- **بکاپ خودکار روزانه**: SQLite online-backup با چرخش نسخه‌ها

## اجرا locally

```bash
cp .env.example .env      # مقادیر را پر کنید
export $(grep -v '^#' .env | xargs)
python bot.py
```

بدون توکن هم می‌توانید منطق را تست کنید:

```bash
DEV=1 DATA_DIR=/tmp/rix python bot.py   # بدون اتصال به تلگرام بالا می‌آید
```

## استقرار روی Railway

1. این ریپو را به Railway اضافه کنید (New Project → Deploy from GitHub).
2. متغیرهای محیطی را ست کنید: `BOT_TOKEN`، `OWNER_TG_ID`.
3. یک **Volume** بسازید و روی `/data` mount کنید (پایگاه‌داده و بکاپ‌ها آنجاست).
4. Deploy. healthcheck از `/health` می‌خواند.

`railway.json` و `Dockerfile` از قبل تنظیم شده‌اند؛ build بدون هیچ نصبی
انجام می‌شود (فقط stdlib).

## نقش‌ها

`owner` > `admin` > `agent` > `readonly` — بررسی نقش در `permissions.require`
انجام می‌شود و با هر پیام تازه از دیتابیس خوانده می‌شود (تنزل فوری اثر می‌کند).

## جریان وریفای مشتری

```
ادمین: دکمه «مشتریان» → «افزودن مشتری» → آیدی عددی
ربات:  getChat چک می‌کند (انسان؟ ربات؟ استارت کرده؟)
       کد ۶ رقمی + دکمه «کپی کد» برای مشتری می‌فرستد
مشتری: کد را می‌فرستد
ربات:  مشتری ثبت و تایید می‌شود، منوی پنلش باز می‌شود
```
